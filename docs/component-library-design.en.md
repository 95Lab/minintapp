# Component library design

| Area | Standard |
| --- | --- |
| Header | Uses the platform logo, menu, language and actual account state. No unavailable-account badge in the demo header. |
| Introduction | A “Demo” label explains that data stays on the page without AI calls, emails or server storage. |
| Runtime | Groups participant/host views, sample poll and quiz, and local answers. |
| Component groups | Clearly separates creation, account/remix/lifecycle and extension placeholders. |
| Sharing | Separate QR column on desktop, stacked on mobile, explicitly marked as an example URL. |
| Mobile and language | From 320 px, one column, touch targets at least 44 px; Vietnamese and English sample content and labels. |

No business APIs are connected to demo actions. Unconnected sample features remain disabled.
