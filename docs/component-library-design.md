# Thiết kế thư viện component

| Khu vực | Tiêu chuẩn |
| --- | --- |
| Header | Dùng logo, menu, ngôn ngữ và trạng thái tài khoản thật của nền tảng. Không thêm badge tài khoản chưa khả dụng vào header demo. |
| Giới thiệu | Nhãn “Bản minh họa”, giải thích dữ liệu chỉ lưu trong trang, không gọi AI/gửi email/lưu server. |
| Runtime | Nhóm giao diện người tham gia/host, mẫu bình chọn và quiz, thử trả lời tại chỗ. |
| Nhóm component | Tạo ứng dụng, tài khoản/remix/lifecycle và điểm mở rộng chia khu vực rõ ràng. |
| Chia sẻ | Cột QR riêng trên desktop, xuống dưới trên mobile, ghi rõ URL minh họa. |
| Mobile và ngôn ngữ | Từ 320 px, một cột, vùng chạm 44 px trở lên; nội dung minh họa và nhãn Việt–Anh. |

Không nối thêm API nghiệp vụ cho các thao tác demo. Tính năng mẫu chưa kết nối tiếp tục bị vô hiệu hóa.

Live Demo được gộp vào `/how-it-works#live-demo`. Menu chỉ còn Cách hoạt động; `/preview` chuyển hướng để giữ các link cũ. Trạng thái trang chủ không còn liên kết chi tiết, footer không có mô tả lưu trữ.
