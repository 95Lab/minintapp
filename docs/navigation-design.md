# Thanh điều hướng

| Thành phần | Thiết kế |
| --- | --- |
| Hình thức | Nền giấy, viền mảnh, góc bo nhẹ, khoảng trắng thoáng; logo hiện có. |
| Điều hướng | Mục hiện tại có chữ đậm màu và đường nhấn cam; giữ nhãn dễ đọc bằng VI/EN/日本語. |
| Ngôn ngữ | Một ô chọn VI / EN / 日本語, vùng chạm 44 px, ngôn ngữ hiện tại hiển thị rõ. |
| Hành động | Tạo app là nút cam; đăng nhập là nút viền nhẹ. |
| Mobile | Logo và đăng nhập luôn hiện; menu mở rộng chứa liên kết, hàng ngôn ngữ và CTA toàn chiều rộng. Escape đóng menu, focus bàn phím rõ. |

Không thay đổi quyền truy cập hay API xác thực. Mục Ứng dụng của tôi vẫn chỉ hiện khi đăng nhập.

Cập nhật: gom VI / EN / 日本語 vào một ô chọn ngôn ngữ duy nhất, bỏ ba nút riêng để giảm điểm bấm cạnh tranh trong menu. Trên mobile, ô chọn chiếm trọn một hàng.
