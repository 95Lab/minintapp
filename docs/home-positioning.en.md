# Homepage positioning

| Message | Content |
| --- | --- |
| Audience | People who do not code can create a quick app from a plain-language prompt. |
| Need | A tool that fits a task or moment: polls, quizzes, draws and expenses. |
| Sharing | Use it immediately and share a link. |
| Community | Introduce turning useful apps into potentially sellable templates; link to the marketplace with an explicit demo label. |

No guaranteed income or claim of live payments. Vietnamese, English and mobile are supported.

The marketplace opportunity uses a warm callout with a heading and a separate orange CTA. Primary actions use terracotta #b94e30 with white text across create navigation, homepage templates, creation confirmation, template library and app list. Content supports Vietnamese and English.
