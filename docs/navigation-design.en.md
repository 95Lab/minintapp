# Navigation bar

| Element | Design |
| --- | --- |
| Appearance | Paper background, thin border, subtle corners, generous spacing and the existing logo. |
| Navigation | Current page uses darker text and an orange indicator; readable VI/EN/日本語 labels. |
| Language | One VI / EN / 日本語 selector with a 44 px touch target and the current language clearly shown. |
| Actions | Orange create action; subtly outlined sign-in action. |
| Mobile | Logo and sign-in remain visible; expanded menu contains links, a language row and a full-width CTA. Escape closes the menu and keyboard focus stays visible. |

Access rules and authentication APIs remain unchanged. My apps remains visible only when signed in.

Update: VI / EN / 日本語 now use one language selector instead of three separate buttons, reducing competing controls. On mobile, the selector occupies one full row.
