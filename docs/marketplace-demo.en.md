# Template marketplace — demo

| Feature | Behavior |
| --- | --- |
| Search | Searches titles/descriptions, supports unaccented Vietnamese, combines with All/Free/Paid filtering. |
| Labels | Simulated Free/Paid labels. All templates remain free to try. |
| Views/clones | Fixed illustrative counts, not actual analytics; creating an app does not inflate the numbers. |
| App creation | Brief confirmation offers keep private (default), list as Free or list as Paid. |
| Limits | The choice is demo UI state only: no API field, saved listing, app publication or payment. |
| Privacy | Future real listings would share templates, not responses or private data. |

Vietnamese and English are supported. Real marketplace listings, analytics and payments are not implemented in this demo.
